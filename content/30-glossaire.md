## Glossaire et sources

| Mot | Définition simple |
| --- | --- |
| Agent | Programme IA qui agit (lit, écrit, lance des commandes) au lieu de seulement répondre |
| API | Guichet par lequel deux logiciels échangent des demandes et des réponses |
| Authentification | Vérifier qui est l'utilisateur |
| Autorisation | Vérifier ce que l'utilisateur a le droit de faire |
| Backend | Partie qui tourne sur le serveur : secrets, calculs, vérifications |
| Commit | Point de sauvegarde nommé dans Git |
| Déployer | Mettre l'application en ligne |
| DNS | Annuaire qui relie un nom de domaine à l'adresse d'un serveur |
| Frontend | Partie affichée dans le navigateur, lisible par tous |
| JSON | Format de texte pour échanger des données entre programmes |
| MRR | Revenu mensuel récurrent, la somme des abonnements d'un mois |
| MVP | Produit minimum viable : la plus petite version utile |
| RLS | Règle dans la base de données qui limite chaque utilisateur à ses propres lignes |
| SaaS | Logiciel utilisé dans le navigateur contre un abonnement |
| Variable d'environnement | Valeur (souvent secrète) stockée hors du code, par exemple dans `.env.local` |
| Webhook | Message automatique qu'un service (Stripe) envoie à ton serveur quand un événement se produit |
